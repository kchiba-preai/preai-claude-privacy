PREAI Claude プライバシーポリシー

制定日：2026年11月17日

株式会社PREAI（以下「当社」）は、社内向けの業務支援アプリ「PREAI Claude」（以下「本アプリ」）での利用者の情報の取り扱いを、次のとおり定めます。本アプリは当社の社員だけが利用するもので、一般には提供していません。

1. 取得する情報

本アプリは、利用者が Google アカウントで許可した範囲で、次の情報を読み取り・書き込みます。

  • Google カレンダー：予定の参照、予定の登録・変更
  • Google タスク：タスクの参照・登録・変更
  • Google ドライブ：利用者が指定した議事録・メモのファイルの参照（読み取りのみ）

2. 利用目的

取得した情報は、利用者本人の業務を助けるためだけに使います。

  • 予定・タスク・議事録から、やるべきことを一覧にする
  • 利用者が承認した予定を Google カレンダーに登録する
  • 利用者が頼んだタスクを Google タスクに登録する

広告、販売、利用者の評価など、上記以外の目的には使いません。

3. 保存場所

取得した情報と認証情報は、利用者本人のパソコンの中だけに保存します。当社のサーバーには送りません。

4. 第三者への提供

取得した情報を第三者に販売・提供しません。ただし、やるべきことの整理や文案の作成のため、AI サービス（Anthropic 社の Claude）に必要な範囲の内容を送ります。法令に基づく場合を除き、これ以外の提供はしません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

6. 許可の取り消しと削除

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本アプリへの許可を取り消せます。本アプリが保存した情報は、利用者のパソコンから本アプリのデータを消すことで削除できます。完了・対応不要から1年たったタスクの記録は自動で消します。
